# Contributing

This repository relates to activities in the Internet Engineering Task Force
([IETF](https://www.ietf.org/)). All material in this repository is considered
Contributions to the IETF Standards Process, as defined in the intellectual
property policies of IETF outlined in the
[Note Well](https://www.ietf.org/about/note-well/) and
[BCP 78](https://www.rfc-editor.org/info/bcp78) and
[BCP 79](https://www.rfc-editor.org/info/bcp79), and are provided outside the
scope of these documents.

All IETF Contributions to this repository are made subject to the terms of the
Contributor License Agreement referenced by the Note Well.

## Other Resources

Discussion of this work occurs on the
[NETMOD Working Group mailing list](https://www.ietf.org/mailman/listinfo/netmod)
([archive](https://mailarchive.ietf.org/arch/browse/netmod/)).

In addition to contributions in GitHub, you can send email to the mailing list.
Please see the mailing list archives for information on that list.
